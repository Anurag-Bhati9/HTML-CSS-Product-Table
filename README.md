# HTML & CSS Product Purchase Table 🛒

A simple and clean **Product Purchase Table** built using **HTML5 and CSS3**. This project demonstrates how to organize product information in an HTML table and style it using CSS.

The table displays product names, quantities, unit prices, individual amounts, and a calculated grand total.

## 📌 About the Project

The **HTML & CSS Product Purchase Table** is a beginner-friendly project created to practice working with **HTML tables and CSS styling**.

It presents structured product purchase information in a clear tabular format, with a blue header, visible borders, centered alignment, and interactive row hover effects.

## ✨ Features

* 🛍️ Product serial numbers and names
* 🔢 Product quantities
* 💰 Unit prices
* 🧮 Individual product amounts
* 💵 Grand total of **₹2,650**
* 🔵 Blue table headers with white text
* 🖱️ Interactive row hover effects
* 📐 Centered table layout
* 🎨 Simple and clean design
* 📋 Clearly visible table borders
* 💻 Pure HTML and CSS implementation

## 🔑 Key HTML Concepts

### Table Structure

The project uses standard HTML table elements:

```html id="0h3c6p"
<table>
    <tr>
        <th>Product</th>
        <th>Quantity</th>
        <th>Price</th>
    </tr>
    <tr>
        <td>Product Name</td>
        <td>2</td>
        <td>₹500</td>
    </tr>
</table>
```

### Hover Effect

CSS can be used to provide visual feedback when the user moves the cursor over a table row:

```css id="5e7k2d"
tr:hover {
    /* Hover styling */
}
```
